# 📄 Naavik Olympiad Landing Page  
Here is the page link:: https://jainstonex.rf.gd/sahil_demo/

## 🎯 Objective of the Page  
The goal of this project was to design and develop a **responsive landing page** for the Naavik Olympiad. The page focuses on providing clear information, engaging visuals, and an easy-to-use registration form for participants.  

---

## ✨ Features Implemented  
- **Responsive Design** – Works seamlessly on desktop, tablet, and mobile devices.  
- **Clean UI** – Minimal, modern, and easy-to-navigate layout.  
- **Form Integration** – Registration form connected with sample testing for validation.  
- **Sectioned Layout** – Structured into hero, about, features, registration, and footer.  
- **Reusable Components** – Modular code for scalability and maintainability.
